# GIZA // NEXUS v0.4.0

NEXUS is the cinematic UI pass for GIZA.

## Core goals

- Bring the real application layout closer to the high-tech target visual direction.
- Preserve the evidence firewall: measured / derived / assumed / unverified remain visibly distinct.
- Make the right-side inspector a permanent workstation panel rather than a temporary floating pop-up.
- Add a bottom mission strip for fast navigation to major locations.
- Keep the Khafre object/photo/spec/provenance bindings from ATLAS.

## UI changes

- Larger hero viewport with scene overlays.
- Dedicated left operations rail.
- Persistent right-side inspector.
- Bottom quick-jump strip.
- Cinematic glass-panel styling and stronger spatial framing.

## Important note

This package is source-complete and syntax-validated. Because sandbox dependency installation is limited, treat screenshots/freeze images as source-faithful previews rather than a production runtime capture.
