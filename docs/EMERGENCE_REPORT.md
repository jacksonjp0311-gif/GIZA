# What Emerges — GIZA v0.10.6

## 1. The strongest pattern is procedural, not numerological

The most stable structure currently visible in the evidence is an **ordered transformation of movement and architectural environment**:

```text
dual lower entry
→ convergence
→ royal-image hall
→ covered / linear ascending causeway
→ controlled upper branch
→ sequential pillared halls
→ royal-image court / deeper rooms
→ inner cult candidates
→ pyramid transition
→ physical closure
→ burial endpoint
```

This pattern is more compelling than isolated ratios because it is assembled from source-addressed room programs, thresholds, finds and access topology. It is still a hypothesis about design grammar, not a recovered ceremony.

## 2. Royal-image encounter is recurrent

The lower Valley Temple has unusually strong statuary evidence, including a 23-position architectural field in current scholarly reconstruction. The upper Pyramid Temple also carries strong royal-image architecture, although exact statue form and placement are disputed.

The important observation is **recurrence at major route states**, not a claim that every image had the same function.

## 3. Movement is repeatedly transformed

The architecture does not behave like one continuous open hall. The current room graph repeatedly exhibits:

- merge / convergence;
- linearization;
- ascent;
- branch choice;
- sequential deepening;
- court circulation;
- inner-zone transition;
- literal portcullis closure.

That makes **access governance** a serious design-grammar candidate across multiple scales. It does not prove social hierarchy or a particular rite.

## 4. The causeway is becoming more important

Cross-source agreement supports a long covered route of roughly 494–494.6 m linking lower and upper complexes. In system terms, it is not merely an edge between two nodes: it changes movement from a temple interior to a constrained, linear, ascending transition before the upper complex.

Whether that transformation was ceremonial in every use remains open.

## 5. A sensory-architecture hypothesis is now testable

Hölscher's excavation monograph describes/reconstructs the Valley Temple pillared hall using a combination of dark red granite, bright alabaster paving, royal statuary and light entering through high openings, with reflected effects on polished surfaces.

That description is not photometry. But it is now a **falsifiable geometry problem**: once the legal 1:100 ARCE plan and opening geometry are registered, GIZA can test what apertures existed, what image positions were visible, and whether the reconstructed light/reveal field is physically plausible.

## 6. Meaning may have been partly enacted

The working hypothesis now worth testing is:

> part of the complex's meaning may have been procedural — generated through ordered movement, encounter, concealment, reveal and access — rather than residing only in static dimensions or symbols.

This is an architectural interpretation, not evidence of software, AI, hidden computation or a future-directed message.

## 7. What could kill the pattern

The hypothesis should weaken if:

- registered plans contradict the assumed room/threshold topology;
- independent sources disagree on key transitions;
- metric visibility shows image fields were not visible from hypothesized route states;
- covered-causeway reconstruction fails under primary plan evidence;
- Khufu/Menkaure comparisons show the same graph arises trivially from generic construction constraints.

The next phase should therefore try to **break** the procedural-grammar model, not decorate it.
