# GIZA v0.2 UX contract

## DISCOVER
Understand a selected object in under ten seconds: what it is, whether it is measured/derived/assumed/unverified, and whether a real photo exists.

## EXPLORE
Rotate, zoom, explode, section-cut and jump between meaningful objects.

## REVERSE ENGINEER
Show source-bound dimensions, coordinates, source locators, provenance and falsifiable questions.

## Object HUD
Every selected entity can open a floating HUD with STORY, SPECS and EVIDENCE tabs plus a photo/diagram carousel. No photo is preferable to a misleading photo.
