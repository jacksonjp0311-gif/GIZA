# GIZA v0.10.11 — Transition Gate

This release arms the transition from remote/source-text evidence to the first archaeological plate-local metric fit. It does **not** claim that transition has occurred.

## Gate

`remote witness -> local bytes -> SHA-256 -> local Plate VI render -> render SHA-256 -> visual confirmation -> frozen controls/holdouts -> unchanged similarity fit -> untouched holdout evaluation -> residual field -> manual promotion review`

The real Petrie fit remains blocked because the exact PDF bytes are not locally held in this runtime. Remote rendering is evidence of plate identity, not byte custody.

## Residual-field rule

If the fit runs, every holdout residual vector is retained. No automatic outlier removal and no post-hoc transform escalation are permitted. A failed fit is a valid experimental result.
