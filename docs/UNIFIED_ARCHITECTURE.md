# GIZA v0.10.6 — Unified Architecture

```text
GIZA NEXUS
├── NEXUS       locked UI/navigation/workstation shell
├── FORGE       semantic 3-D + masonry analysis lattice
├── VAULT       evidence maturity/receipts/promotion
├── CANON       source authority/rights/conflicts/material priors
├── FIELD       spatial registration/uncertainty/acquisition
├── FRAME       modular application/scene boundaries
├── SIMLAB      reproducible physics: GRAVITY / ECHO / STRATA
├── OBSERVATORY normalized real-world evidence backbone
├── REGISTER    exact rows / discrepancies / claim & source-status audit
├── ATLAS INGEST rights-aware open-media evidence
├── REGISTRATION LAB camera/photo registration
├── CONTROL NET survey frames / orientation / control bridging
├── ARCHIVE HARVEST confirmed-source knowledge corpus
├── PRIMARY SOURCE VAULT source-byte custody / checksums / parser lineage
├── INTENT RECONSTRUCTION competing explanatory models / falsifiers
├── SOURCE PARSER source-addressed datum normalization / parser receipts
├── ACTION GRAPH place → action → place behavioral reconstruction
├── PRIMARY PLAN PARSER plan/source extraction with custody gates
├── ROOM GRAPH room → threshold → room topology
├── PLAN CONCORDANCE independent-source agreement/dependence/conflict
├── VISIBILITY LAB pre-metric depth / branch / chokepoint analysis
├── RITUAL MAP  scrollable cartographic intelligence inside central viewport
├── FINDINGS    persistent research summaries
├── CONTINUITY  provider-agnostic handoff
└── DESIGN      machine-readable NEXUS visual contract
```

Authority flows downward from source custody and parsed evidence toward behavioral and intent interpretation. SOURCE PARSER cannot increase authority; ACTION GRAPH and RITUAL MAP may synthesize or visualize upstream state but cannot mutate canonical geometry, evidence maturity, survey transforms, or photo-registration state.


## v0.10.5 extension

`PRIMARY PLAN PARSER → PLAN CONCORDANCE / ROOM GRAPH → VISIBILITY LAB → RITUAL MAP` is a one-way interpretive/read path unless an explicit metric promotion receipt is issued. VISIBILITY LAB currently computes zero metric rays.


## v0.10.6 extension

SOURCE-BYTE REGISTRATION now sits between plan/room synthesis and any future metric geometry. METRIC VIEW LAB consumes only registered wall/opening geometry; current registered-plan and ray counts are both zero. Remote URLs, scale bars and schematic room coordinates cannot bypass this gate.
