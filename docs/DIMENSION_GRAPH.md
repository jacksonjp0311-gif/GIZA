# GIZA v0.10.8 // Dimension Graph

The dimension graph preserves scalar dimensions reported in Petrie chapter XIV independently of unregistered Plate VI pixels. Imperial-to-SI conversion is exact, but Petrie's qualifiers (`about`, `over`, `as much as`) are retained.

This permits scalar consistency tests now while refusing to pretend that a collection of lengths uniquely determines the temple plan.

**Rule:** scalar dimensions can constrain a future registration; they cannot create 2-D wall polygons, doorway positions, or visibility rays by themselves.
