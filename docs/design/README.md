# GIZA NEXUS UI baseline

This directory is the canonical design handoff for future maintainers and AI coding models.

Read `LAYOUT_CONTRACT.json` first for machine-readable shell locks, then `COMPONENT_CONTRACT.json`, `VISUAL_REGRESSION.md`, and the root `docs/DESIGN_SYSTEM.md`.

The primary brand is **GIZA NEXUS**. STRATA, ECHO, GRAVITY, FIELD, FINDINGS and future modules are capabilities inside GIZA; they do not replace the workstation identity.
