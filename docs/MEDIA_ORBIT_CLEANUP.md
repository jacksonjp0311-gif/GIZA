## Repeatable media audit

Run `node scripts/media/audit-duplicates.mjs`. The audit hashes every raster under public and scans public JSON media references plus the inscription catalog. Current inventory: 17 raster files, 75 media references, no byte-identical local files, 16 source identities referenced across catalogs/attribution records, and no repeated identity within an individual audited catalog. Preserve those cross-catalog records: they carry object bindings and attribution, not additional independent observations.

Historical source records are not deleted. Quick-view thumbnails can intentionally reuse an image for different actions; those buttons are not a photo collection.

This is an exact-byte/source-identity audit, NOT a complete perceptual near-duplicate assessment of all remote imagery. Remote image bytes were not exhaustively downloaded or compared.
