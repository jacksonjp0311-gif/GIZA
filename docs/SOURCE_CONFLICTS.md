## Main rules

**Petrie vs later rounded exterior dimensions.** Keep Petrie's four measured sides and measured slope as the metric backbone. Hölscher, Ministry summaries, and modern rounded dimensions remain comparison context.

**143.5 m vs 143.8656 m.** These are not silently averaged. 143.8656 m is Petrie's derived height from measured base/slope. 143.5 m is retained as official/historical design-summary context.

**Current vs original height.** Current eroded height and reconstructed original height are different semantic quantities, not competing measurements.

**Measured slope vs 4:3 design relation.** Use measured slope for geometry. Keep 4:3 as an architectural-design hypothesis/crosscheck.

**Deep SAR claim.** No independently reproduced measurement in this corpus supports the modeled 648 m shafts/helices/terminal chambers. Those entities remain UNVERIFIED.
